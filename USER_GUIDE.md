# Quick Reference Guide - New Features

## 🎯 Profile Management

### How to Edit Your Name
1. **Click** the avatar or name in the top-right corner
2. **Select** "Edit Name" from dropdown
3. **Type** your new name in the Profile Modal
4. **Click** "Save" to apply changes
5. ✅ Your name updates everywhere in the app

### How to Add/Change Profile Picture
1. **Click** the avatar or name in the top-right corner
2. **Select** "Add Picture" from dropdown
3. **Choose** an image file from your computer
4. **Preview** the image before uploading
5. **Click** "Upload Picture" to apply
6. ✅ Profile picture updates immediately

## 🔔 Notifications

### Viewing Notifications
1. **Click** the bell icon 🔔 in the top-right corner
2. **See** all notifications with timestamps
3. **Different colors** indicate notification types:
   - 🟢 Green = Success (Login, profile updates)
   - 🔵 Blue = Info (Generation started)
   - 🟡 Yellow = Warnings/Errors

### Managing Notifications
- **Click** on a notification to mark it as read
- **Click X** on individual notifications to dismiss them
- **Click** "Clear all notifications" to remove everything
- **Red badge** on bell shows unread count

### Types of Notifications You'll See
- ✅ Assignment Created
- 🔄 Question Generation Started
- 🚀 Login Successful
- 👤 Profile Updated
- ⚠️ Generation Failed (if applicable)

## 📝 Creating Assignments (Updated)

### The New Table Layout
1. **Fill in** basic details (Title, Due Date, Description)
2. **Upload** your reference material (PDF or TXT)
3. **Configure** question types using the new **table**:
   - **Desktop View**: Clean table with 4 columns
   - **Mobile View**: Card layout with grouped fields

### Using the Question Configuration Table
```
| Question Type          | No. Questions | Marks | Total |
|------------------------|---------------|-------|-------|
| Multiple Choice Q.     |       ▼ 4 ▲   |  ▼1▲ |   4   |
| Short Questions        |       ▼ 3 ▲   |  ▼5▲ |  15   |
| Diagram/Graph Based    |       ▼ 5 ▲   |  ▼5▲ |  25   |
```

### Step-by-Step
1. **Select** a question type from dropdown
2. **Use +/- buttons** to set number of questions
3. **Use +/- buttons** to set marks per question
4. **See total** auto-calculate in the Total column
5. **Click Add Question Type** to add more rows
6. **Click X** on any row to remove it
7. **View** total questions and marks in summary

## 📚 Assignment Library (Dashboard)

### Finding Assignments
- **View** all assignments in a grid layout
- **Search** by title using the search bar
- **See** assignment stats: Questions, Marks, Due Date

### Using the Three-Dot Menu (⋮)

Each assignment card has a **three-dot menu** in the top-right:

```
┌─────────────────────┐
│ Assignment Title  ⋮ │  ← Click here
├─────────────────────┤
│ Description text... │
│ Questions: 25 M: 60 │
│ Due: Dec 15, 2024   │
└─────────────────────┘
```

**Click the ⋮ to see options**:
- 👁️ **View Assignment** - Open full details page
- 🗑️ **Delete** - Remove assignment (asks for confirmation)

### Card Information
- **Assigned Date**: When you created the assignment
- **Due Date**: When the assignment is due
- **Status Badge**: Completed ✅ / Processing 🔄 / Failed ❌
- **Questions & Marks**: Total count

## 🆘 Troubleshooting

### Profile Picture Not Uploading?
- Make sure file is a valid image format (JPG, PNG, GIF, WebP)
- Check file size (typically under 5MB works best)
- Try a different image file

### Notifications Not Showing?
- Click the bell icon again to refresh
- Make sure notifications are enabled in your browser
- Clear all and trigger a new action to see fresh notifications

### Assignment Not Appearing in Library?
- Refresh the page
- Check if it's still being processed
- Try searching for it
- Check the status badge

### Three-Dot Menu Not Opening?
- Make sure you clicked exactly on the ⋮ icon
- Try clicking elsewhere first to close any open menus
- The menu should appear below or to the side
